## Наши фичи (PR #227, ветка feature/transcription-sound-volume)

Поверх `origin/main` (коммит `1981d489`):

- **Transcribe with Prompt хоткей** — второй хоткей для диктовки с выбранным AI-промптом
- **Overlay показывает имя промпта** — `NotchContentState.promptModeOverrideProfileName`
- **AI gate fix** — AI работает при выбранном промпте, даже если toggle выключен (см. ниже)
- **`isProviderConfigured()`** — новый метод для проверки только наличия API key/endpoint

## Проектные соглашения

### `isConfigured()` — bypass при выбранном промпте

Это **намеренное поведение**, не баг. Подробнее: см. раздел в `CLAUDE.md`.

Коротко: выбор кастомного промпта = явный сигнал "хочу AI", независимо от мастер-toggle.
